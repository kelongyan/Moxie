方案 C · 沉浸树形

密度最高

设计要点

  • 30px 紧行：单行 + 更窄间距，一屏条目最多（比 A 多 ~15%）。
  • 分组带底色块：分组行用 inset 底 + 全宽通栏，区块感最强，像「抽屉」。
  • 去 chevron 桌面化：分组 chevron 只在 hover 浮现，平时靠文件夹图标——更安静的静态观感。
  • 激活行通栏染：打开行整行 accent-soft（不留左条位），信号强。
  • 取舍：底色块用得比其他方案多，「安静」程度让位于「结构感」。
试试：对比 A/C 的密度差异；悬停分组看 chevron 浮现；拖拽落点；切深色看分组底色块。

适合场景

  • 分组多、文件多，重度整理型用户
  • 喜欢 VS Code 式结构感、想最大化一屏信息
