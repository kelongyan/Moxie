# 侧栏文件列表重构方案（v2.3 · 单行索引卡）

> 基准：main（0c8d413，收藏已移除）· 撰写日期：2026-09-11
> 范围：`src/components/SidebarView.tsx`、`src/state/sidebar.ts`、`src/styles/app.css`（侧栏段）、`src-tauri/src/recent.rs`（仅阶段 2）
> 设计语言：延续 v2.0「安静的纸」——明度分层、彩色稀缺、刻度化、无新依赖
> 自主设计，不参考外部项目。

---

## 0. TL;DR

**现状一句话**：侧栏文件行是「两行灰字塞进 32px」——标题 13px + 目录副标题 12px 上下紧贴，每行结构完全相同，扫读没有锚点；分组行（26px）比文件行（32px）还矮，层级倒挂；拖拽落点、缺失文件、移除操作全部没有视觉响应。

**方案一句话**：文件行**单行化**——图标 + 文件名 + 行尾状态区，路径信息退到 tooltip；激活行用「指示条 + 图标与文字 accent」双重信号；缺失行 hover 浮现「重新定位」按钮；最近文件行 hover 浮现 X 直达移除；分组行补 chevron、升到 28px、拖拽落点高亮。阶段 2（可选）给最近文件加**相对时间**（"12 分钟前 / 昨天"），让"最近"二字名副其实。

**预期**：信息密度减半、扫读速度翻倍、每个状态都有"下一步"入口；侧栏从"能用的列表"变成"精致的索引"。

## 2. 诊断

**D1 · 两行文字挤在 32px 里。** 13px + 12px 两行文字无 line-height 控制，实际内容 ≈30px，上下各剩 1px——"挤"是结构性的。且 12px 副标题与 13px 主标题字号太接近，主次不分，每行看起来像两行模糊的灰。

**D2 · 副标题信息错位。** 「最近文件」的核心语义是**什么时候碰过它**，不是**它在哪个目录**——目录名是低频信息却占掉 50% 行面积。路径只在"同名文件"场景有用，却让所有行都付双行代价。

**D3 · 扫读无锚点。** 每行（灰图标 + 黑标题 + 灰副标题）结构完全一致，一列下来全是均匀灰；唯一的状态信号是打开行的 2px 短条——太安静了，安静到没有层次。

**D4 · 分组层级倒挂。** 分组行 26px < 文件行 32px，"容器"比"内容"矮；展开/收起只靠文件夹开合图标区分，没有 chevron 的一致语言（区块头有 chevron，分组反而没有）。

**D5 · 拖拽落点是盲区。** 拖文件到分组时无高亮、无插入指示，松手才知道落没落对——交互成本全靠猜。

**D6 · missing 态没有行动。** 65% 透明度 + 警告图标只传达"坏了"，不传达"怎么修"；重定位藏在右键第 1 项，用户第一反应是点击（无响应）。

**D7 · 高频操作藏太深。** 最近文件"移除"是高频轻操作（清理误入列表的文件），现在要走右键菜单 5 项里的最后一项。

**D8 · 语言图标全灰。** 10+ 种语言共用一个灰，扫读时图标零信息量。（自主决策：**不引入语言彩色**——「彩色稀缺」是 v2.0 的灵魂，扫读靠文件名与时间，图标保持灰阶，激活行才用 accent。）

## 3. 设计方向：「单行索引卡」

> 最近文件是一叠索引卡：一眼一行、状态浮在行尾、路径悬停即见。

三条原则：

1. **一行一事**：每行只承载"一个文件"的身份（图标 + 名字），其余信息按状态浮现（行尾）或悬停（tooltip）。
2. **状态即按钮**：行的每一种非正常状态（打开中 / 缺失 / 可移除）都在行尾给出**可点击的下一步**，而不是只给颜色。
3. **容器高于内容**：分组行（容器）必须 ≥ 文件行（内容），且与区块头共享 chevron 语言。

## 4. 分项设计

### 4.1 文件行 FileRow v2（单行 32px）

```
┌──────────────────────────────────────────────────┐
│ ▎ ◆ 报告-final.md                        [×]     │  ← hover：行尾浮现 X
│ ▎ ◆ 笔记.md                              2分钟前  │  ← 阶段2：时间
└──────────────────────────────────────────────────┘
  ↑3×14 指示条（打开中 accent，否则透明）
```

- **结构**：`[指示条][图标 16px][文件名 flex-1][行尾状态区]`；删除 `.row-text/row-subtitle` 双行结构。
- **文件名**：13px / 400；**打开中** 500 字重（双重信号之一）。
- **指示条**：2→3px 宽、高 17→14px，`transition height/opacity 120ms`；打开中 accent。
- **图标**：打开中 `--lac-accent`，其余 secondary（不变）。
- **tooltip**：整行包 `<Tooltip label={path}>`（复用现有组件，600ms 延迟），副标题退场后路径信息零损失。
- **行尾状态区**（均 24px 命中、hover 才浮现，`opacity 0 → 1 / 80ms`）：
  - **最近文件行**：X 图标（14px）→ `removeRecent(path)`；提示"移除"。
  - **分组文件行**：X 图标 → `removeFromGroup(groupId, path)`。
  - **missing 行**：FolderSearch 图标（14px，warning 色）→ 直接触发现有重定位流程（promptInput → 校验 → replacePath → 打开）；行不响应打开点击。
- **交互零变更**：右键菜单全部保留（含从列表移除——菜单与 hover X 双入口）；拖拽发起保留；点击打开保留。

### 4.2 分组行（28px + chevron + 拖拽高亮）

- 行高 `--lac-group-row-height` 26 → **28px**；结构 `[chevron 12px][文件夹图标][名称][计数]`。
- **chevron**：与 section-header 同语言（12px、tertiary、expanded 旋转 90°、`--dur-1`）；点击整行展开不变。
- **计数**：保持裸数字但 `tabular-nums`（已有）+ `min-width: 16px; text-align: right`。
- **拖拽高亮**（新增 `.drop-target`）：`onDragOver` 给行加类——背景 `--lac-accent-soft` + `inset 0 0 0 1px color-mix(accent 40%, transparent)`，`transition background 80ms`；`onDragLeave/onDrop` 移除。拖拽状态用 `useState<string | null>`（当前悬停的 groupId）。
- **空分组展开态**：显示 12px tertiary 占位「拖入文件，或右键分组添加」。

### 4.3 区块头与布局

- 区块间距 `.sidebar-scroll` gap 16px → **14px**（分组内已是紧凑层级，区块间略收）。
- 区块头、区块头 trailing（垃圾桶）不变。
- 空状态文案/按钮保留，按钮统一 `--ctl-sm` 档（现有 26px 高 → 24px）。

### 4.4 missing 态

- 行不再整体降透明度——改为**文件名 tertiary + 警告图标**（信息不丢，层次仍在）。
- hover 浮现「重新定位」按钮（见 4.1 行尾），行动直达。

### 4.5 不引入的东西（自我约束）

- ❌ 语言彩色图标（彩色稀缺原则；激活态 accent 已够分层）。
- ❌ 文件树（产品决策不变）。
- ❌ 行内多按钮工具条（一个 X 封顶，其余归右键菜单）。
- ❌ 任何新依赖、新颜色令牌。

## 5. 阶段 2（可选）· 最近文件相对时间

**价值**：「最近」的语义补全——"2 分钟前"比目录名更该出现在行尾；扫读时时间是最好的召回锚点。

- **数据层**：`recent.rs` 条目从 `String` 升级为 `{ path: String, lastOpenedMs: u64 }`（JSON 文件结构 `RecentFiles.json` 同步迁移：读取时兼容旧 `string[]`，视为 ts=0）。
- **IPC**：`recent_list` 返回 `Vec<RecentEntryDto>`（`#[serde(rename_all = "camelCase")]`：path / lastOpenedMs）；`recent_add/remove/replace/clear` 签名不变（add 内部写 now）。前端 `sidebar.ts` 的 `recent: string[]` → `recent: RecentEntry[]`，契约改动双侧同步。
- **展示**：行尾 11px tertiary `relativeTime(ms)`：`<60s 刚刚 · <60m N 分钟前 · <24h N 小时前 · <7d N 天前 · 今年内 M月D日 · 更早 YYYY/M/D`；`font-variant-numeric: tabular-nums`；与 hover X 互斥（hover 时 X 替换时间位）。
- **风险**：IPC 契约变更——按项目惯例双侧同步 + 单测锁定；旧 JSON 兼容读取必须覆盖（已列验收）。
